# Macae

A responsive draw-and-guess interface.

## Project structure

```
macae/
├── index.html       # Page structure and UI markup
├── css/
│   └── style.css    # All visual styles and responsive rules
├── js/
│   └── app.js       # Canvas tools, timer, undo/redo and chat UI
└── endlessai_org20261030_155956_page1.png  # Original design reference
```

## Local preview

Open `index.html` in a browser. No build step or package installation is required.

## Notes

The drawing and chat currently run locally in the browser. Real-time multiplayer needs a backend/realtime service.
